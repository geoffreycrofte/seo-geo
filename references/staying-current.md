# Staying current

Search and AI discovery change fast; this skill is a baseline, not the last word. Its review date is `metadata.last-reviewed` in `SKILL.md`.

## When

When the task is more than a small edit, or when the review date is older than about six months.

## How

1. **Search for the latest practices** before applying anything from memory, starting with the sources below.
2. **Compare** what you find with the skill. Prefer primary documentation over blogs, and dated, recent sources over undated ones.
3. **Apply** what is confirmed, and **tell the user** what changed, with the sources.
4. **Propose an update to the skill** (and its review date) when a practice is outdated or a new one is well established. Do not edit the skill silently.
